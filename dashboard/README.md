# Local dashboard

Maintained source for the dashboard installed at `~/inflection-jobs/ui/`. Run with the project's
Python environment; `INFLECTION_DSN` defaults in the existing app to `postgresql:///inflection`.
The dashboard binds only to `127.0.0.1:8765` and retains the existing local job integration.

Data & process reads the report generated by `python -m inflection.process_health`. Detection audit
reads the source/review audit. Financial ratios share `inflection.snapshots`; price checks share
`inflection.market_history`. Processing-health reports contain no stock rankings.

Apply the new database migrations before deploying these files. Deployment must preserve any
concurrent application edits and retain the previous runtime files for rollback.
