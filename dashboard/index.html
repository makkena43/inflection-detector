Inflection

Daily pulls all data (prices, deals, announced dividends, filings listed, downloaded and processed), then refreshes the long-term lists and the short-term scan. If a day is missed, the next run starts from where the data stopped (prices, filings, BSE data and corporate actions all reach back to the last complete run). Files whose text is fully read are then removed from disk; the text stays in the database. Every step retries twice on failure, and Sundays (or Weekly) add a 30-day gap sweep. Daily also builds packets, engine triage and the code triage (fixed rules, no Haiku) for any week that has closed, so a week is reviewed the first day after it ends. Weekly runs the same steps and reuses today's data pull if there was one. The Mac stays awake during a run.
